# 自律监督示例 — Baseline v1

提交时间：2026-10-08T20:10:29.365Z

### 产品是什么

一个通过摄像头监督在场、离席会扣心的自律工具。


### 使用场景 / 用户目标

用户在学习或工作时希望获得在场监督。


### 核心产品设定

屏幕中的虚拟玩偶展示摄像头识别的在场情况；监督中离席会扣心，可申请临时离席免罚。


## 第一版 MVP 功能

## P0-1 · 在场监督

### 功能描述

通过摄像头监督用户是否在场。


### 用户意图

帮助用户在自律时明确当前行为与结果。


### 生效状态 / 条件

正常监督状态。


### 完整规则与边界

监督开始后持续显示摄像头识别的人体存在状态。


### 已确认例外 / 冲突解决规则

无已确认例外


### 验收要求（Human）

### Agent 可以检查什么

检查摄像头读取和状态更新逻辑。


### 人工测试步骤

真人坐在镜头前后离开镜头，对照当前识别状态。


### 可观测要求

开发时显示实时识别结果和当前监督状态。


### 预期人工结果

有人和无人状态随实际情况变化。


## P0-2 · 离席扣心

### 功能描述

监督期间离席超过约定时长会扣心。


### 用户意图

帮助用户在自律时明确当前行为与结果。


### 生效状态 / 条件

正常监督状态。


### 完整规则与边界

连续超过 10 秒无人则扣一颗心；本次离席只扣一次，检测到人后重置离席计时。


### 已确认例外 / 冲突解决规则

用户每连续监督 30 分钟获得一次临时离席机会；主动点击后进入临时离席状态，最多 60 秒，该状态不执行普通离席扣心规则，期满恢复普通监督。


### 验收要求（Agent）

### Agent 验证步骤

模拟正常监督连续 11 秒无人，再持续无人并重新入座。


### 预期 Agent 结果

只扣一颗心，入座后计时重置。


## P0-3 · 临时离席免罚

### 功能描述

允许短暂离席而不扣心。


### 用户意图

帮助用户在自律时明确当前行为与结果。


### 生效状态 / 条件

用户主动点击进入临时离席状态。


### 完整规则与边界

允许离席 60 秒不扣心；超过 60 秒恢复普通监督。


### 已确认例外 / 冲突解决规则

用户每连续监督 30 分钟获得一次临时离席机会；主动点击后进入临时离席状态，最多 60 秒，该状态不执行普通离席扣心规则，期满恢复普通监督。


### 验收要求（Agent）

### Agent 验证步骤

模拟进入免罚状态，推进计时到 60 秒及超过 60 秒。


### 预期 Agent 结果

允许时段不扣心，期限结束恢复普通监督。
